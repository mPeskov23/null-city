Match rules|Reglas de la partida
Five rounds. A correct answer earns 1 point; an error or skip earns 0. Answer once per round. A round ends when everyone answers or time runs out. Each player may use Pulse once per match to eliminate one wrong option. Everyone has the same ability. The highest score wins; equal top scores tie. Earn 20 arena XP per correct answer and a new level every 100 XP. Three correct answers in finished matches per UTC day grant 40 extra XP once that day. Arena XP is separate from the solo story wallet.|Cinco rondas. Cada respuesta correcta vale 1 punto; un error u omisión vale 0. Solo puedes responder una vez por ronda. La ronda termina cuando todos responden o se agota el tiempo. Cada jugador puede usar Pulso una vez por partida para descartar una opción incorrecta. Todos tienen la misma habilidad. Gana quien más puntos obtiene; las puntuaciones máximas iguales empatan. Cada acierto da 20 XP de arena y cada 100 XP subes de nivel. Tres aciertos en partidas terminadas durante un día UTC dan 40 XP extra una sola vez ese día. La XP de arena es independiente del saldo de la historia individual.
If disconnected, return to the same room. The server timer keeps running; reconnecting restores the current state. Spectators watch but cannot answer.|Si pierdes la conexión, vuelve a la misma sala. Local story|Historia local
Without an account, progress, appearance, settings and notes are stored in this browser's localStorage. Game commands run inside a simulation and are not sent to real network targets. Clearing site data removes the local copy; settings allow save export.|Sin cuenta, el progreso, la apariencia, los ajustes y las notas se guardan en el localStorage de este navegador. Los comandos se ejecutan en una simulación y no se envían a objetivos reales. Borrar los datos del sitio elimina la copia local; puedes exportar la partida desde los ajustes.
Server mode stores email, name, bio, avatar, salted password hash, sessions, friendships, messages, match participants and results. Solo progress is sent only by the Save to server button. Email is hidden from other operators. Name, bio, avatar, online status, chat and results are visible to signed-in participants.|El servidor guarda email, nombre, biografía, avatar, hash de contraseña con sal, sesiones, amistades, mensajes, participantes y resultados. El progreso individual solo se envía al pulsar Guardar en el servidor. El email no se muestra a otros operadores. Nombre, biografía, avatar, estado en línea, chat y resultados son visibles para los participantes conectados.
Sessions and security|Sesiones y seguridad
Sign-in uses a secure session cookie lasting up to one day. It is required for accounts and not used for advertising. Passwords are not stored as plain text. IP addresses are used in memory for rate limiting; request messages and secrets are not written to application logs. There is no third-party analytics.|El acceso usa una cookie de sesión segura de hasta un día. Es necesaria para las cuentas y no se usa para publicidad. Las contraseñas no se guardan en texto claro. Las IP se usan en memoria para limitar solicitudes; mensajes y secretos no se escriben en los registros de la aplicación. No hay analítica de terceros.
Export and deletion|Exportación y eliminación
Your profile can export account data as JSON and results as CSV, remove your avatar or end your session. Automatic account deletion is not implemented: before a public launch, the operator must provide a deletion request channel and define retention periods. This edition is for local team demonstrations; do not enter sensitive personal information. Private backups may contain the same data as the database.|Desde el perfil puedes exportar tus datos en JSON y resultados en CSV, eliminar el avatar o cerrar sesión. No se ha implementado la eliminación automática de cuentas: antes de un lanzamiento público, el responsable debe ofrecer un canal de solicitud de eliminación y definir los plazos de conservación. Esta edición es para demostraciones locales del equipo; no introduzcas datos personales sensibles. Las copias privadas pueden contener los mismos datos que la base.
Who manages the data|Quién gestiona los datos
The team running this NULL CITY instance manages the data. It must establish a responsible contact, retention periods and applicable requirements before opening public registration. In a local installation, the computer owner manages the database. This describes implemented behavior, not full legal certification.|Los datos los gestiona el equipo que ejecuta esta instancia de NULL CITY. Debe definir un contacto responsable, plazos de conservación y requisitos aplicables antes de abrir el registro al público. En una instalación local, el propietario del ordenador gestiona la base. Esto describe el funcionamiento implementado, no una certificación jurídica completa.

Participation rules|Reglas de participación
Use your own account. Do not post passwords, other people's personal data, harassment, spam or illegal content in public chat. Do not disrupt the server or other accounts. The instance owner may restrict an offender's access through database administration.|Usa tu propia cuenta. No publiques contraseñas, datos personales ajenos, acoso, spam o contenido ilegal en el chat público. No interrumpas el servidor ni cuentas ajenas. El propietario de la instancia puede restringir el acceso de infractores mediante la administración de la base.
Game and rewards|Juego y recompensas
The arena has five rounds, identical questions and a shared timer. The server accepts one answer per round and awards one point per correct answer. Disconnection does not pause the timer. Equal top scores tie. XP and items are virtual, cannot be bought with money and have no monetary value. Character appearance does not affect results.|La arena tiene cinco rondas, preguntas idénticas y un temporizador compartido. El servidor acepta una respuesta por ronda y da un punto por acierto. Desconectarse no detiene el temporizador. Las puntuaciones máximas iguales empatan. La XP y los objetos son virtuales, no se compran con dinero y no tienen valor monetario. La apariencia del personaje no afecta al resultado.
Training boundaries|Límites de la práctica
Actions inside the simulator do not grant permission to test real systems. Practice outside the game only in your own lab or within an explicitly agreed scope.|Las acciones del simulador no dan permiso para comprobar sistemas reales. Practica fuera del juego solo en tu laboratorio o dentro de un alcance expresamente autorizado.
